- 只读的 gh 命令（pr/issue/run/release/repo 的 list 与 view、pr checks、auth status、不带写参数的 gh api）不再被当成“无法证明只读的改动”，也就不再反复出现验证提示。关联 #13293。
- Read-only gh commands (list and view of pr, issue, run, release and repo, pr checks, auth status, gh api without write options) are no longer treated as an unproven change, so they stop raising the verification prompt. Refs #13293.
