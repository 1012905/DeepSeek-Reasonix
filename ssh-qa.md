# Real SSH sidebar integration

Date: 2026-10-17, Asia/Singapore. Source baseline:
`3d983ca0f31439b4e37a9291e99540601c1003d7` plus this worktree's local changes.

## Environment and evidence

The browser used the production frontend build, the current Studio host, and a
Linux x86_64 kernel reached through a configured SSH alias. OpenSSH host key
checking remained enabled. A second alias resolved to the same machine; it was
not counted as an independent second host. Machine identifiers are omitted here.

Both machines used identical disposable project and transcript paths.
Separate physical files contained distinct local and remote markers. The initial
history was seeded with the real session store; it was not generated by a model.

Both kernels used disposable Reasonix homes. No provider credentials were copied
and no chat submission or paid model request was used for this test.

An authenticated loopback proxy recorded only routing fields and timings. Selected
real responses were held for 3500 ms after the kernel answered, without replacing
their status or body. This forced asynchronous selection ordering over real SSH.

Evidence set: `ssh-real/` in the private QA artifacts. Screenshots and routing
records are retained locally and are not committed.

## Confirmed findings and repairs

| Finding | Root cause and repair | Regression evidence |
| --- | --- | --- |
| Configured remote project was ignored before a pane opened. | The hub attached an empty workspace for history reads. A shared resolver now supplies the configured default for both reads and unqualified opens. | Both Go regression subcases failed before the repair; real SSH history then loaded from the test project. |
| A remote configuration conflict looked like an unread history. | The frontend discarded every HTTP 409. It now preserves the kernel's typed refusal. | `hub.test.ts` exercises `remote.serve_provider_mismatch`. |
| An existing SSH conversation was called a new conversation. | Pane titles searched only local history. Remote titles now match host, project and transcript in the remote book. | Window regression plus real transcript/title/selection checks. |
| A successful manual read left the host labelled disconnected. | The read did not refresh host state. Manual refresh now rereads the host book too. | Remote project interaction regression. |
| Returning to a pending session silently ignored the latest click. | Loading CSS disabled pointer events. Rows remain clickable while the open owner deduplicates pending requests. | Failed real pointer sequence before the repair; production CSS guard and real repeated-click retest afterward. |
| Several SSH panes eventually blocked normal browser requests. | A paused fallback stream reported zero connection cost and was resumed outside the budget. It now retains its dedicated-stream cost while paused. | Composed mux/budget regression failed before the repair; nine-pane production browser retest afterward. |

The requested scope covers selecting existing sessions, choosing the target of a
new session, asynchronous selection ordering and deduplication. It does not
establish model execution, native Electron window behavior, or release readiness.

Wallet requests can report missing-credential errors in the deliberately
unconfigured test homes. These are distinct from navigation or transport failures.
Development hot-reload diagnostics were excluded from the final production run.

## Retrospective

Component tests without production CSS missed discarded pointer clicks. Budget
tests without the real mux adapter missed the connection-cost mismatch. The
desktop UI skill now requires the composed interaction/transport checks for
pending navigation; no new protocol or persisted format was introduced.

## Cleanup and outcome

The disposable local Studio host, test proxies and remote kernel were stopped.
Only this run's project, isolated homes and workspace-specific remote launch
files were removed. The pre-existing remote kernel was still running afterward.

Non-secret evidence was retained in the evidence directory. The original local
preview on port 5275 remains available. No commit, push or release was performed.

Final result: passed for the requested navigation, new-session and repeated-click
scope, after repairing the six findings above.
